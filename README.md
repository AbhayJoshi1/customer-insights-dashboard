# Customer Insights & Recommendation Dashboard

## Project Overview
This project analyzes customer behavior, sales trends, regional performance, and customer segmentation using Power BI. The dashboard provides interactive insights and business recommendations to support data-driven decision-making.

## Objectives
- Analyze customer and sales data.
- Identify high-value customers.
- Study regional sales performance.
- Analyze top-performing products.
- Generate business recommendations.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Word

## Dataset
Sample Superstore Dataset

## Key Performance Indicators
- Total Sales
- Total Orders
- Total Customers
- Average Order Value

## Dashboard Visualizations
- Sales by Month
- Sales by Region
- Top 5 Products
- Customer Segmentation
- Interactive Slicers

## Customer Insights
1. The West region contributes the highest sales.
2. High-value customers generate major revenue.
3. Top products contribute significantly to sales.
4. Sales vary across different months.
5. The company serves a diverse customer base.

## Business Recommendations
1. Focus on high-value customers.
2. Maintain inventory for top-selling products.
3. Improve low-performing regions.
4. Introduce loyalty programs.
5. Use sales trends for planning.
